# SillyTavern 美化反馈助手

![美化反馈助手 Logo](assets/theme-feedback-logo.png)

作者：酒疫
版本：0.2.1
最低 SillyTavern 版本：1.14.0

这是一个面向手机独立酒馆的私人美化反馈插件。它允许在手机酒馆中截取当前界面、用手指圈出问题并填写说明，再通过固定 HTTPS 中转服务把截图与反馈资料写入私人 GitHub 收件箱，供电脑端 Codex 拉取处理。

## 正确数据流

```text
手机独立运行酒馆
→ 用户主动截图、圈画并确认上传
→ Netlify HTTPS 私人中转
→ 私有 GitHub 反馈仓库
→ 电脑端 Codex 读取并处理
```

公开插件仓库不保存截图、聊天内容、GitHub Token或私人上传码。

## 能做什么

- 只有点击“截取当前界面”时才截图。
- 只有预览后点击“上传私人反馈”才发送。
- 支持现代 CSS `color()`、`color-mix()`、`oklch()` 等颜色语法。
- 用手指直接在截图上圈画问题。
- 自动记录当前主题、订阅版本、当前窗口、本地修改状态和设备视口。
- 上传前自动缩放并压缩为 WebP，避免手机长截图超过中转请求限制。
- 按“主题名称 / 版本名称 / 反馈编号”写入私有 GitHub 仓库。

## 0.2.1 修复

- 点击插件时不再触发酒馆的抽屉自动收起逻辑，角色编辑或角色卡界面会保持在原处。
- 截图引擎在空闲时提前加载，主题版本联网核对改为后台执行。
- 截图画布直接进入标注区，取消中间的 PNG 编码与再次解码，手机等待时间更短。

## 手机安装

在 SillyTavern 的“安装第三方扩展”中填写：

```text
https://github.com/jiuyi777/sillytavern-theme-feedback
```

安装或更新后刷新酒馆。右下角出现“美化反馈”入口即表示前端已加载。

## 首次设置

1. 打开“美化反馈”。
2. 展开“私人中转设置”。
3. 确认已自动填写 `https://jiuyi-theme-feedback-relay.netlify.app/api/theme-feedback`。
4. 填写私人上传码并点击“保存中转设置”。

中转地址和上传码只保存在当前手机酒馆的扩展设置中，不写入公开仓库。

## 使用

1. 切换到需要反馈的主题与问题窗口。
2. 点击“截取当前界面”。
3. 用手指圈出问题。
4. 填写问题说明。
5. 点击“上传私人反馈”。
6. 记录成功提示中的反馈编号。

以后可以对电脑端 Codex 说：

> 查看私有美化反馈仓库里“草莓编辑部”的最新反馈。

## 私有仓库结构

```text
feedback/
└─ 草莓编辑部/
   └─ 测试版 0.5/
      └─ 20260817.../
         ├─ screenshot.webp
         └─ feedback.json
```

## 安全边界

- Netlify 中转不保存任何 GitHub Token；反馈先进入私人 Blobs 暂存区。
- 私有收件箱使用仓库自带的 GitHub Actions 权限定时拉取，权限只覆盖该仓库。
- 手机端必须提供至少 20 字符的私人上传码。
- 中转服务只接受 PNG、JPEG 或 WebP，单图最多 4 MB。
- 手机端不能指定仓库、分支或任意保存路径。
- 反馈仓库必须保持 `PRIVATE`。
- 不自动上传聊天，不在打开插件或截图时发送任何内容。

## 中转服务部署

项目中的 `netlify/functions/theme-feedback.mts` 是 HTTPS 中转函数。生产环境需要配置：

- `THEME_FEEDBACK_UPLOAD_SECRET`：至少 20 字符的私人上传码。
- `THEME_FEEDBACK_SYNC_SECRET`：至少 32 字符，只由私有仓库的 Actions 使用。

私有仓库同时保存同一个 `THEME_FEEDBACK_SYNC_SECRET` 为 Actions Secret，并通过定时工作流把反馈提交到 `feedback/`。

不要把前两个秘密写入 `.env` 后提交，也不要使用公开客户端变量前缀。
